# Zoom Out

Find the entrypoints, nearby instructions, relevant knowledge, and recent
decisions for the area. Inspect only what is needed to answer the current
orientation question; skip unavailable or irrelevant history.

Give one compact map: what the area does, where its behavior lives, which
constraints matter, and where to look next. If code and documentation
disagree, verify the current behavior and flag the stale claim. Avoid a
file-by-file inventory when a few paths explain the structure.
