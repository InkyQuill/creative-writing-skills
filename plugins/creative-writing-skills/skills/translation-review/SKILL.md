# Translation Review

Read the direction contract and relevant fixed context before judging prose.
Use $project-maintenance for mechanical checks and $translation-memory for
accepted conventions. Use [review rubric](resources/review-rubric.md) for a
focused fidelity pass, literary pass, or both.

When the user requests Hieronymus or the nearest project agreement or binding
refers to it, load $hieronymus-integration before choosing review evidence. Apply
the free-text memory agreement by source role and scope. A convention selected
from Hieronymus does not require a Markdown record, and an active Hieronymus rule
does not overrule an agreement that assigns the current decision elsewhere.

Treat the selected primary edition as the content authority. A disagreement with
an auxiliary translation is a comparison finding, not automatically an error in
the new translation. Consider official precedent within the approved inheritance
policy. Identify source extraction problems separately from translation choices.

Check meaning, omissions, invented explanations, agency, negation, address,
subtext, deliberate ambiguity, and reveal timing. Then assess target-language
rhythm, register, imagery, dialogue and narrator/character distinctions. Prefer
specific supported diagnoses over generic advice to make prose smoother.
Do not normalize a distinctive voice into neutral prose.

Each finding needs a source locator, target locator, explanation and practical
impact. Quote only the relevant short passage or reference the unit/scene.
Distinguish definite errors, conflicting accepted decisions, and optional
literary alternatives. Never invent unread evidence. If the needed source is
unavailable, say which judgment cannot be made and review independent material.

Keep review notes separate from accepted prose. A request for review alone does
not authorize changes. When revision is requested, use the guarded draft workflow;
recheck changed passages and joins. Mark reviewed only after actually completing
the requested review. Technical coverage checks and a successful command do not
certify literary quality or authorize acceptance.
