# Information Hierarchy

Lead with the result or useful decision. Put evidence and explanation where a
reader will need them, then offer deeper reference material only if it helps.
Make headings say what each section contributes.

Choose a form for the information: prose for reasoning, a table for a small
comparison, a diagram for relationships, and an example for an abstract rule.
Use a visual only when it makes the relationship easier to understand. Keep
short answers short.

In an interactive artifact, reveal secondary detail on request. In a plain
document or chat, use order and links instead. The reader should understand
the main point without operating a control or following a source link.
