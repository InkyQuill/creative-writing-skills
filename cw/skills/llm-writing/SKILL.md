# LLM Writing

Know who will read the text and what they need to take from it. Check relevant
notes before drafting. Give each paragraph one job, and lead with the useful
point. If the text is long, use `/information-hierarchy` to choose its shape.

Revise from structure to sentences. Cut repetition, generic transitions,
unearned certainty, and claims without evidence. Keep uncertainty visible
where it affects a decision. Preserve the author's voice in creative work;
use `/creative-writing-craft` for fiction prose.

Write to a file only when the task calls for a file. Otherwise deliver the
text in the response.
