# Literary Translation

Translate from the chosen edition into the chosen direction. Use this skill
standalone or through /creative-writing-muse. Load /project-maintenance for
project mechanics, /translation-memory for terminology and voices, and
/translation-review for fidelity and literary review. Read
[workflow](resources/workflow.md) for the working sequence.

## Establish the task

Read the project contract and relevant edition/direction records. Use
/project-setup when no project exists. Support a standalone translation project
without requiring worldbuilding, character biographies, or an author manuscript.
An existing author project keeps its manuscript in place.

Ask only for missing information that materially changes the translation:
which version to produce, which source controls meaning, or a disputed literary
choice. Never assume English is a pivot language or Russian is the target.
Multiple editions and directions can share a language; use their identities.

Resolve source coverage for the requested volume. Treat the selected primary
edition as the content authority. Use auxiliary editions only within the
approved strategy. If the main source is itself a translation, state the
indirect provenance. Never silently substitute an available auxiliary for a
missing primary. Continue independent readable units while a specific unit is
blocked, and identify the affected source and output in ordinary language.

## Translate with literary continuity

Preserve meaning, deliberate ambiguity, subtext, unreliable narration, and the
timing of revelations. Do not add explanations or simplify a distinctive voice
merely to make the text smoother. Match the target language's natural expression
without flattening rhythm, register, address, or imagery. Treat adaptation of
wordplay and cultural references as decisions with evidence and alternatives.

Build a fixed translation context with relevant scene entities and relationships.
Read the selected primary text, applicable memory, accepted comparisons and
neighbors. Neighbor excerpts are context only, not extra text to translate.
For a new long direction, propose a representative trial passage when useful;
do not require a separate pilot for a directly requested passage.

An official translation can establish precedent, not infallibility. In an
English continuation, follow the approved inherited English names and voice
choices. In a Russian direction with Japanese as primary, English wording is
reference evidence; choose Russian solutions independently. Record deviations
from inherited practice instead of silently standardizing them.

Save prose as a draft through the domain command. Record observations and
proposals separately; do not promote them into accepted memory just because a
translation was generated. Preserve source tags and author-only boundaries.
Pass hidden context only to a trusted translator; never copy it into output or
into a character/reader simulation packet.

## Finish the requested pass

Run the relevant mechanical checks and a literary review proportional to scope.
A reviewed status records an actual completed review, not successful file
creation. Accept prose only within the user's existing authorization; a request
for a draft alone does not authorize replacing accepted text. Report the result,
remaining affected units and unsettled decisions. Do not describe a technical
check as proof of literary quality.
