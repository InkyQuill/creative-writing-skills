# Layout and theme

Start with semantic HTML and a single readable column. Add a wider grid only
where comparison or navigation benefits from it. Use relative sizing, wrap
long text, and test at roughly 375px width. Keep interactive controls easy to
tap and visible in keyboard focus.

Define a small set of CSS color variables for text, background, borders, and
accents. Choose contrast before decoration. A theme switch is optional; if
added, it must update embedded graphics as well as surrounding text and
preserve the reader's choice. Prefer native CSS and JavaScript. If a library
is necessary, verify its current version and bundle it for offline delivery.
