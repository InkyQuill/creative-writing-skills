# Translation Memory

Use /project-maintenance for recoverable record operations and
/story-memory for general story knowledge boundaries. Read
[record guidance](resources/records.md) when creating or changing memory.

Separate shared identity from target-language expression. Record that Japanese
and English names refer to one entity only when supported; keep the Russian
rendering in its own direction. Permit identical surface forms for different
meanings and different forms for the same entity. Never implement a glossary as
an unconditional string replacement across prose.

Keep original observations distinct from target-language instructions. Cover
narrator voices, character voices, relationships, register, address, and changes
through the story. Write accepted style instructions imperatively, with examples
and allowed variation. Preserve evidence from the source or an explicit user
decision and identify the edition, volume, chapter/scene or unit.

Use observed for a pattern found in an edition, proposed for a suggested rule,
accepted for a settled decision, and superseded for a replaced decision. An
explicit user answer settles its stated scope without another confirmation.
An approved inheritance policy may settle names but not voices: honor its exact
scope. Official publication alone does not turn every observed pattern into a
rule for every target language.

Store unresolved observations and proposed alternatives without making them
operative rules. Do not mark a semantic inference accepted merely because it
seems likely. Retain the source tags and author-only knowledge boundaries.

Apply scoped exceptions only within their declared volumes, units, entities or
relationships. A late-volume revelation must not clarify an intentionally
ambiguous early passage. Use explicit supersession to resolve precedence;
report conflicting accepted rules instead of picking one by recency.

When a rule changes, preserve its predecessor and review the dependent prose.
New rules also affect existing contexts. Do not rewrite accepted translations
as a memory side effect. Give concurrent translators fixed contexts, collect
proposals separately, and reconcile accepted memory centrally.
