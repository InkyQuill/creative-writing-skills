# Decision Grill

Use this when the author wants to test a direction, settle a disputed choice,
or sharpen a term. Read the relevant plan, project vocabulary, and prior
decisions before challenging an assumption. Do not turn ordinary drafting into
an interview.

Find the choice that blocks the next step. State the tradeoff and ask one
focused question, with a recommendation when the evidence supports one. Wait
for the answer before following a new branch. If existing notes conflict,
quote the specific conflict rather than treating one source as a rule.

When the choice settles, summarize what was decided and what remains open.
Update project notes only when the author asked for documentation or the active
task already includes it. Provisional story ideas remain provisional; use
`/kb-management` only for decisions the author has confirmed as durable.
