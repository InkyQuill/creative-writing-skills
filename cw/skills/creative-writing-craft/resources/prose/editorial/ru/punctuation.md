# Пунктуация сложного предложения

Нормы этого файла — значения по умолчанию для пунктуации русских сложных предложений и вводных слов при редакторской проверке; правила и договорённости проекта в `project.md` их перекрывают. Это правила об обязательной, механической пунктуации: проверяй по ним без запроса подтверждения; авторскую пунктуацию как осмысленный приём сохраняй, когда она намеренна и подтверждена текстом проекта.

## A. Пунктуация в сложном предложении

### A.1. Запятая перед подчинительными союзами

- Отделяй придаточное предложение запятой. Границу отмечают союзы и союзные слова: **что, который, где, когда, если, чтобы, потому что, так как**.
- Базовое правило: запятая ставится перед союзом, начинающим придаточное.
- Переноси запятую влево вместе с ограничительной или усилительной частицей, стоящей перед союзом: граница сдвигается, но не исчезает: `возвращайся только когда я позову` → `возвращайся, только когда я позову`. Частицы: только, лишь, исключительно, как раз, даже, ведь, всё же (ПАС § 116–117; Розенталь § 33.6). Ошибка — убрать запятую совсем потому, что частица выглядит частью главного предложения: это не так, придаточное остаётся придаточным.

Когда запятая перед «что» не нужна:

| конструкция | запятая | правило |
|---|---|---|
| составной союз остаётся целым | нет внутри | «потому что» — одно целое; запятая перед «потому», не перед «что» |
| отрицание + что | нет | устойчивое выражение: «не то что обидно» |
| смысловая цельность | нет | «делай что хочешь» — неразложимо |
| что = вопросительное местоимение | нет | «что случилось?» — не союз |
| союзы при последующем «то» | нет | между «что» и «если» запятой нет, когда дальше следует «то» |
| параллельные придаточные с «и» | нет | «я знаю, что он придёт и что поможет» — перед вторым «что» запятой нет |

Составные союзы — где ставить запятую:

- Разрывай составной подчинительный союз, когда автор акцентирует причину или условие: запятая переходит с начала придаточного на первую часть союза.
- Нейтрально: запятая перед всем союзом («потому что», «для того чтобы»).
- С акцентом: запятая после первой части («потому, что»; «для того, чтобы»).
- Тот же шаблон: несмотря на то(,) что; в связи с тем(,) что; ввиду того(,) что; благодаря тому(,) что.

### A.2. Тире между подлежащим и сказуемым

- Ставь тире, когда подлежащее и сказуемое выражены одной частью речи без связки.

| подлежащее | сказуемое | тире |
|---|---|---|
| существительное (им. п.) | существительное (им. п.) | да: Москва — столица России |
| инфинитив | инфинитив | да: Жить — Родине служить |
| существительное (им. п.) | инфинитив | да: Наша задача — дождаться темноты |
| инфинитив | существительное (им. п.) | да: Читать — большое удовольствие |
| числительное | числительное | да: Дважды два — четыре |
| существительное (им. п.) | это/вот/значит + существительное | да: Язык — это инструмент мышления |

Тире не ставится:

1. «не» перед сказуемым: Бедность не порок.
2. Подлежащее — личное местоимение: Он врач (но: Он — это тот, кто поможет).
3. Между ними вводное слово, наречие, союз или частица: Собака тоже друг; Вода словно зеркало.
4. Сказуемое перед подлежащим (инверсия): Замечательный человек ваш отец.
5. Между ними как/будто/словно: Глаза как звёзды.

### A.3. Двоеточие

1. Обобщающее слово перед перечислением: В сундуке нашли: кинжал, компас, флягу.
2. Бессоюзное сложное — причина (= потому что): Я не пошёл: поднялась температура.
3. Бессоюзное — уточнение (= а именно): Погода была ужасная: дул ветер, шёл дождь.
4. Бессоюзное — дополнение (= что): Я чувствовал: что-то изменилось.
5. Прямая речь после слов автора: Он сказал: «Я уже здесь».

### A.4. Точка с запятой

1. Распространённые параллельные члены с внутренними запятыми.
2. Значительно распространённые части бессоюзного сложного предложения.
3. Строчные пункты списка (правила пунктуации списков — в разделе об однородности списков `grammar.md`).

### A.5. Вводные слова

- Выделяй вводные слова и обороты запятыми с двух сторон в середине предложения и одной запятой в начале или в конце.
- Не выделяй запятыми не вводные: ведь, вот, именно, между тем (= тем временем), примерно — и другие частицы и наречия, ошибочно принимаемые за вводные (всё-таки, даже, как бы, поэтому, притом, причём, якобы и т. д.); полная таблица — в разделе B ниже.

## B. Ловушки с запятой — справочная таблица

- Применяй мнемонику: если слово можно убрать без потери смысла и грамматики — оно вводное, запятая нужна; если нельзя — это член предложения, запятой нет.

| конструкция | запятая? | правило |
|---|---|---|
| как будто | нет | частица-союз, не вводное |
| как правило | да, с двух сторон | вводное (указывает на норму) |
| в том числе | запятая перед | присоединительный оборот, уточнение |
| кроме того | да, после (в начале); с двух сторон (в середине) | вводное |
| тем не менее | по связи; не вводное | уступительное наречное сочетание, не вводное: запятая ставится по связи частей («устал, тем не менее продолжал»), а не с двух сторон; в начале предложения запятая после — факультативна |
| однако (в начале) | нет после | противительный союз (= но) |
| однако (в середине/конце) | да, с двух сторон | вводное слово |
| наконец (итог перечисления) | да | вводное: во-первых… наконец |
| наконец (= наконец-то) | нет | наречие, обстоятельство времени |
| значит (= следовательно) | да, с двух сторон | вводное |
| значит (= означает) | нет | сказуемое: Жить — значит бороться |
| таким образом (= итак) | да | вводное, подведение итога |
| таким образом (= таким способом) | нет | наречие образа действия |
| во-первых, во-вторых | да, после | вводное, порядок аргументов |
| может быть / может | да | вводное, предположение |
| конечно | да | вводное, уверенность |
| конечно (= безусловно, да) | нет (в ответе) | утвердительная частица |
| кстати | да | вводное, попутное замечание |
| кстати (= к месту) | нет | наречие: Замечание пришлось кстати |
| правда (= действительно) | да | вводное |
| правда (= но, хотя) | нет (запятая перед, как перед союзом) | союз со значением уступки |
| видимо | да | вводное, предположение |
| казалось бы | да, с двух сторон | вводное |
| между прочим | да | вводное, попутное замечание |
| например | да | вводное; после него двоеточие, если следует перечисление |
| по-моему, по-твоему | да | вводное, маркер мнения |
| действительно (в начале = да) | да | вводное, подтверждение |
| действительно (= на самом деле, в середине) | нет | наречие-обстоятельство |
| в частности | да | вводное, уточнение |
| с одной стороны… с другой стороны | да, каждая часть | вводные, парная конструкция |
| прежде всего (= во-первых) | да | вводное |
| прежде всего (= в первую очередь) | нет | обстоятельство |
| в свою очередь (= между тем) | да | вводное (в публицистике) |
| в свою очередь (= ответно) | нет | обстоятельство |
| к сожалению | да | вводное, эмоциональная оценка |
| к счастью | да | вводное, эмоциональная оценка |
| по крайней мере | да (обычно) | вводное, ограничение |
| впрочем | да, после (в начале); с двух сторон (в середине) | вводное, уступка |
| итак | да, после | вводное, вывод |
| следовательно | да | вводное, вывод |
| безусловно | да | вводное, уверенность |
| несомненно | да | вводное, уверенность |
