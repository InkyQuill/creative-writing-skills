# Creative Writing Craft

How fiction works on the page: prose technique, scene mechanics, and style
analysis. This is the how-to-write layer. Keep five axes independent:
production mode is the operation, market genre is the reader promise,
manuscript language supplies grammar and idiom, prose profile supplies a
literary register, and author voice is the project's evidenced execution.
`/writing-principles` carries reader-reward diagnostics;
`/creative-writing-modes` carries production modes.

## Resolve the Prose Stack

Before prose production or surface review, resolve resources in this order:

1. universal prose base: `resources/prose/base.md`;
2. exact manuscript-language defaults under `resources/prose/languages/`,
   using the primary tag (`ru-RU` → `ru`, `en-GB` → `en`);
3. the prose-profile base under `resources/prose/profiles/`, plus its matching
   language adapter when the profile provides one;
4. applicable project-wide `kb/styles/` references and their approved
   `kb/samples/` evidence;
5. narrower narrator, POV, character, or scene style references and evidence;
6. the current author brief.

Grammar and orthography in the language resource are the floor. Project
conventions choose among valid variants. A profile shapes register but cannot
override grammar. Evidence-backed author voice overrides generic matters of
taste; narrower voice overrides broader voice. Intentional nonstandard usage
overrides a normal rule only when documented and evidenced. Canon, source tags,
and character knowledge boundaries remain absolute.

No prose profile means `general`: use the universal base and language defaults
without a profile overlay and without asking a confirmation question. An
unsupported or missing language is never silently treated as English. Use
explicit project evidence when it is sufficient; ask one focused question only
when the missing language norm would materially change the work.

Load only the other resource needed for the task:

- `resources/scene-construction.md` — scene entry, dialogue, pacing, transitions.
- `resources/style-analysis.md` — analyzing evidence samples and producing scoped style references.
- `resources/genre/` — market-genre craft guidance when a reader promise shapes the page.
