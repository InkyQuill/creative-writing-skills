# Beat Sheets

Positional guides for the five structure models. Percentages are defaults to
react against, not targets to hit — a beat lands where the story's pressure
puts it, and the percentages exist so you can notice when a load-bearing beat
is badly late or early. Structures are guides, not rules; mix and adapt as
the story demands.

Choose by what the story is doing: tightly paced commercial fiction tends to
Three-Act or Save the Cat; quest and transformation stories to Hero's
Journey; quiet, idea-driven, or slice-of-life stories to Kishotenketsu;
tragedy and ensemble drama to Five-Act.

## Three-Act

| Beat | Position | Job |
|---|---|---|
| Setup | 0–25% | world, POV voice, the ordinary pressure |
| Inciting incident | ~10% | the disruption arrives |
| First plot point | ~25% | the POV commits; no way back |
| Confrontation | 25–50% | rising complications, stakes sharpen |
| Midpoint | ~50% | reversal or truth that reframes the goal |
| Crisis | ~75% | the worst outcome; the plan fails |
| Climax | 75–95% | the confrontation the story earned |
| Resolution | 95–100% | the new ordinary, charged with change |

## Hero's Journey

| Beat | Position | Job |
|---|---|---|
| Ordinary world | 0–10% | who the character is before |
| Call to adventure | ~10% | the disruption |
| Refusal | 10–15% | the cost stated aloud |
| Mentor | ~15% | guidance, tool, or truth |
| Crossing the threshold | ~20% | into the special world |
| Tests, allies, enemies | 20–50% | learning the new world's rules |
| Approach | ~45% | the inmost cave prepared for |
| Ordeal | ~50% | death and rebirth of the old self |
| Reward | 50–75% | seizing the sword |
| The road back | ~75% | the world resists the change |
| Resurrection | ~90% | the final test of the new self |
| Return with the elixir | 90–100% | the change brought home |

## Save the Cat (15 beats)

| Beat | Position | Job |
|---|---|---|
| Opening image | 0% | the before, in one picture |
| Theme stated | ~5% | the question the story argues |
| Set-up | 1–10% | the flawed ordinary |
| Catalyst | ~10% | the disruption |
| Debate | 10–20% | resistance and stakes |
| Break into two | ~20% | the choice that starts the story |
| B story | ~22% | the relationship that carries the theme |
| Fun and games | 20–50% | the promise of the premise |
| Midpoint | ~50% | false victory or false defeat; stakes rise |
| Bad guys close in | 50–75% | pressure external and internal |
| All is lost | ~75% | the whiff of death |
| Dark night of the soul | 75–80% | the despair that teaches |
| Break into three | ~80% | the synthesis that saves |
| Finale | 80–99% | the proving ground |
| Final image | 100% | the after, in one picture |

## Kishotenketsu (four acts)

No central conflict required; the engine is twist and recontextualization.

| Act | Position | Job |
|---|---|---|
| Ki (introduction) | 0–25% | establish the situation and characters |
| Sho (development) | 25–50% | deepen without turning |
| Ten (twist) | 50–75% | an unexpected element recontextualizes everything |
| Ketsu (reconciliation) | 75–100% | the parts reconcile into new meaning |

## Five-Act

| Act | Position | Job |
|---|---|---|
| Exposition | 0–20% | world, pressures, fault lines |
| Rising action | 20–45% | complications compound |
| Climax | 45–55% | the turn; often the middle, not the end |
| Falling action | 55–85% | consequences unwind |
| Catastrophe / resolution | 85–100% | the tragic or settled outcome |

## Using a Beat Sheet

Map the story's actual beats to the model after drafting direction, not
before: the sheet is a diagnostic grid, not a template to fill. When a
load-bearing beat (first plot point, midpoint, all is lost, ten) sits far
from its default position, ask whether the story is doing something
deliberate or whether the beat is missing and the structure sags. Track
which model the project chose in the planning notes so later passes evaluate
against the same grid.
